# Engineering Standards

> Personal engineering standards, architecture decision
> records, and project playbooks developed over 7+ years
> of production data engineering experience.

These standards are stack-agnostic and apply to any
data engineering project regardless of technology,
company, or scale.

## Contents

- **Engineering Standards** — 10 universal principles
  that govern every technical decision
- **Decision Records** — ADR template used across
  all projects
- **Project Playbooks** — step-by-step build sequences
  for common DE project types
- **Code Standards** — Python coding standards
  for data engineering

## Philosophy

Good engineering is not about knowing the right tools.
It is about making the right decisions, in the right
sequence, for the right reasons — and being able to
explain why.
